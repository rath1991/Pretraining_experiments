# Experiments

Documented outcomes for each training run.

## Structure
One file per experiment: `exp_01_optimizer_warmup.md`, `exp_02_init_scaling.md`, etc.

## Template
Each experiment file should cover:
- **Config** — what was changed, full hyperparameters
- **Hypothesis** — what you expected to see
- **Results** — loss curves, key metric values, screenshots/plots
- **Observations** — what actually happened
- **Interpretation** — what it means, questions it raised
- **Next** — what this suggests for the next experiment
